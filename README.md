# Очень странные дела — Хоукинс

Интерактивный квест для живой игры на проекторе: карта Хоукинса под туманом войны,
гирлянда-шифр в доме Байерсов, три локации и финальный бой с Демогоргоном.

- `Hawkins/` — квест (стартовая точка)
- `Demogorgon/` — финальный бой, открывается из квеста

## Ведущему

- **M** — панель ведущего (переходы по локациям, «открыть все», сброс)
- **F** — полный экран
- **ESC** — назад к карте

Прямые ссылки на экраны: `Hawkins/#map`, `#byers`, `#police`, `#lab`, `#radio`, `#school`.

Послания гирлянды и загадка настраиваются в блоке `CONFIG` в начале `Hawkins/index.html`.
Чего не хватает из визуала и промпты для генерации — в `Hawkins/ПРОМПТЫ-ДЛЯ-ГЕНЕРАЦИИ.md`.
