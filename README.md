# Битва с Демогоргоном

Интерактивный бой у проектора: класс школы Хоукинса, 12 предметов на выбор,
шкала HP босса и панель ведущего.

Открывается с корня: **https://doodoniel.github.io/hawkins-quest/**

## Ведущему

- **M** — панель ведущего (HP, попадание, промах, урон, музыка, сброс)
- **F** — полный экран
- **ESC** — снять выбор предмета

Ход: игрок выбирает предмет в классе → ведущий жмёт «Попадание» или «Промах» →
при попадании вводит урон с кубика.
